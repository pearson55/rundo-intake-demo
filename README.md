# RunDo 客户收资流程 Demo

润建股份 RunDo 能源与能碳管理平台客户收资的可交互前端 Demo。

## 在线演示

部署 GitHub Pages 后访问：`https://pearson55.github.io/rundo-intake-demo/`

## 功能

- 能源管理平台、能碳管理平台两套收资表单
- 根据项目主体动态显示字段
- 分步填写、必填校验、明细表增删行
- 浏览器本地草稿自动保存
- 信息确认与流程完成页
- 离线导出真正的 `.xlsx` 文件
- JSON 数据备份导出

## 本地运行

直接用现代浏览器打开 `index.html`，或在本目录运行 `python3 -m http.server 8080`，然后访问 `http://localhost:8080`。

## 数据与隐私

这是纯前端 Demo，没有后台数据库。草稿使用浏览器 `localStorage` 保存，不会自动上传。附件选择后只读取并导出文件名，不上传附件原文件。演示时请使用虚拟企业信息。

“确认完成”表示完成页面内的信息整理流程，不代表已向公司后台提交。若用于正式业务，还需接入后端接口、数据库、身份认证、权限控制和附件存储。

## 技术栈

HTML、CSS、原生 JavaScript、SheetJS（已内嵌，Excel 导出可离线使用）。
